# BookMySpa logo: Steam Lotus

A three-petal lotus with steam rising from it: calm, warm, unmistakably "spa".

## Files
| File | Use |
|---|---|
| `bookmyspa-logo.svg` | Full logo (symbol + name) on light backgrounds |
| `bookmyspa-logo-on-dark.svg` | Full logo on dark backgrounds |
| `lotus-mark.svg` / `png/lotus-mark-1024.png` | Symbol alone, light backgrounds (transparent) |
| `lotus-mark-on-dark.svg` / `png/lotus-mark-on-dark-1024.png` | Symbol alone, dark backgrounds (transparent) |
| `lotus-app-icon.svg` / `png/app-icon-512.png` | App / Play Store icon |
| `lotus-favicon.svg`, `png/favicon-32.png`, `png/favicon.ico` | Browser tab (steam left out so it stays crisp when tiny) |
| `png/apple-touch-icon.png` | iPhone home-screen icon |
| `png/instagram-profile-1080.png` | Instagram / WhatsApp Business profile picture |

The full-logo SVGs use the Marcellus and Figtree fonts from Google Fonts, so they need an internet connection to show the right lettering.
For a printer or a PNG of the full logo, export the Steam Lotus board from the logo canvas.

## Colours
Eucalyptus `#2F5D50` · Sage `#4C7A6A` · Mist `#EDF1EC` · Amber `#D99A3E` · Night `#1F1B24`

## Rules
- Keep clear space around the logo of at least the height of the lotus's centre petal.
- Smallest size: 24 px tall for the symbol, 120 px wide for the full logo.
- Don't recolour the petals, stretch, rotate, or add shadows.
